# Calculadora Web

Calculadora desarrollada en React y TypeScript.

## Características

* Interfaz basada en componentes reutilizables.
* Operaciones básicas:

  * Suma (+)
  * Resta (-)
  * Multiplicación (*)
  * División (/)
* Botón de igual (=).
* Botón de limpieza (C).
* Soporte para números decimales.
* Manejo de errores para resultados inválidos.
* Límite de 9 caracteres en el display.
* Implementación de pruebas unitarias con Vitest y Testing Library.
* Documentación visual de componentes utilizando Storybook.
* Tipado estático mediante TypeScript.

## Tecnologías utilizadas

* React
* TypeScript
* Vite
* Vitest
* Testing Library
* Storybook
* ESLint

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/Sofilayerdi/Calculadora-web.git
```

Entrar al directorio del proyecto:

```bash
cd Calculadora-web
```

Instalar dependencias:

```bash
npm install
```

## Ejecutar la aplicación

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

La aplicación estará disponible en:

```text
http://localhost:5173
```

## Generar versión de producción

```bash
npm run build
```

## Ejecutar pruebas

```bash
npm test
```

## Ejecutar Storybook

```bash
npm run storybook
```

Storybook estará disponible en:

```text
http://localhost:6006
```

## Ejecutar lint

```bash
npm run lint
```
